# Maeve visual asset provenance

Cowboy confirmed that both runtime images were created for the Maeve/THS project and approved them for repository inclusion:

- `ui/assets/fort_wayne_skyline_2560x1440.png`
- `ui/assets/maeve_foreground_transparent_v2.png`

The Fort Wayne skyline also supports Maeve's planned seven-inch Raspberry Pi home dashboard. Maeve was implemented on the computer first so the certified headset workflow could progress without requiring immediate purchase and assembly of room-monitor hardware.

This statement records project ownership and publication approval only. It does not claim a third-party license or identify an image-generation tool or license.
